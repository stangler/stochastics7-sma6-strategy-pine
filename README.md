# ストキャス7×SMA6 逆張り検証(FX 5分足)

TradingView Pine Script v6 用の逆張りストラテジーです。7つのストキャスティクス期間（フィボナッチ数列）と6本SMAの組み合わせで売買シグナルを生成し、エントリー・決済のアラートにも対応しています。

## 概要

複数のストキャスティクス期間を同時に監視し、一定数以上が買われすぎ/売られすぎゾーンに入った後、SMAの向きが変わったところで逆張りエントリーします。FXの5分足を想定していますが、他の時間足や銘柄でも使えます。

関連: インジケーター版は [stochastics7-indicator-pine](https://github.com/stangler/stochastics7-indicator-pine)（7本のストキャスの表示とパネル）です。

## 特徴

- **マルチ期間ストキャスティクス**: 7つの期間（5, 8, 13, 21, 34, 55, 89）を同時に監視
- **逆張りロジック**: 売られすぎ＋SMA上向きでロング、買われすぎ＋SMA下向きでショート
- **柔軟な判定設定**: 判定に必要なストキャスの本数や、ゾーン到達からの許容本数を調整可能
- **ドテン**: 逆シグナル発生時にポジションを反転
- **リスク管理（任意）**: 利確/損切り（pips指定）、最大保有本数、時間帯フィルター
- **アラート**: 確定前の「予告」、足確定時の「エントリー」、約定時の「決済」。メッセージはスクリプト内で完結

## インストール

1. TradingViewでPineエディタを開く
2. `stochastics7-sma6-strategy.pine` の内容を貼り付ける
3. 「保存」→「チャートに追加」
4. ストラテジーテスターでバックテストを確認

## パラメーター設定

### ストキャス期間

| パラメーター | 初期値 |
|------------|-------|
| 短期1 / 短期2 | 5 / 8 |
| 中期1 / 中期2 / 中期3 | 13 / 21 / 34 |
| 長期1 / 長期2 | 55 / 89 |

### 判定

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| %K平滑化 | 1 | %Kの平滑化期間 |
| 買われすぎライン | 80 | 買われすぎと判定するレベル |
| 売られすぎライン | 20 | 売られすぎと判定するレベル |
| 判定に必要な本数 | 7 | 買われすぎ/売られすぎと判定するために必要なストキャスの本数（1〜7） |
| ゾーン到達からエントリー許容本数 | 3 | 判定が出てからこの本数以内なら、SMAの向きでエントリー。0なら判定が出た足のみ |
| SMA期間 | 6 | エントリー判定に使うSMAの期間 |

### 売買設定

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| ロング（売られすぎ＋SMA上向き） | オン | ロングを有効化 |
| ショート（買われすぎ＋SMA下向き） | オン | ショートを有効化 |
| 逆シグナルでドテン | オン | 逆シグナルでポジションを反転 |
| サイン発生の1本目のみエントリー | オン | オン：条件が揃った最初の足だけエントリー。オフ：条件が続く間、決済のたびに再エントリー |
| 1pipの価格幅 | 0 | 0で自動（最小値幅×10）。銘柄に合わせて手動指定も可（例：ゴールドで1pip=1ドルなら1） |
| 利確 pips | 0 | 0で無効 |
| 損切り pips | 0 | 0で無効 |
| 最大保有本数 | 0 | 0で無効。指定本数に達したら時間切れで決済 |

### 表示

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| SMAテーブルを表示 | オン | チャートにSMAの価格と向きを表示する |
| テーブルの位置 | top_right | 表示位置（top_left / top_right / bottom_left / bottom_right） |

### アラート

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| アラートメッセージを出す | オン | スクリプト内のメッセージで通知する |
| 確定前の予告アラートも出す | オン | 足の途中で条件が揃った時点で「予告」を通知する |
| メッセージをSlack用のJSON形式にする | オフ | オンにすると `{"text":"..."}` 形式で通知する（Slack通知用） |

### 時間帯フィルター

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| 取引時間帯を限定 | オフ | 時間帯フィルターの有効/無効 |
| 取引時間帯 | 0800-2400 | エントリーを許可する時間帯 |
| タイムゾーン | Asia/Tokyo | 時間帯の基準 |
| 時間帯の外に出たら決済 | オフ | 時間帯外になったら全ポジションを決済 |

## トレードロジック

### エントリー条件

**ロング**
1. 判定に必要な本数以上のストキャスが売られすぎライン以下になってから、許容本数以内
2. SMAが上向き（現在値 > 1本前）
3. サイン発生の1本目のみ（初期設定）
4. ロングが有効、時間帯フィルターを通過（使用時）

**ショート**
1. 判定に必要な本数以上のストキャスが買われすぎライン以上になってから、許容本数以内
2. SMAが下向き（現在値 < 1本前）
3. サイン発生の1本目のみ（初期設定）
4. ショートが有効、時間帯フィルターを通過（使用時）

エントリーは足の確定時に判定し、次の足の始値で約定します（バックテストと同じ条件）。

### エグジット条件

- **利確・損切り**: エントリー価格からのpips（エントリー注文と同時に指定）
- **ドテン**: 逆シグナルで反転
- **最大保有本数**: 指定本数に達したら決済
- **時間帯外**: 「時間帯の外に出たら決済」がオンの場合

## アラート

### 設定方法

1. アラートを作成し、条件に本ストラテジーを選ぶ
2. トリガーに **「alert()関数呼び出しのみ」** を選ぶ
3. 作成する（メッセージ欄の入力は不要）

トリガーを「注文の約定とalert()関数呼び出し」にすると、TradingView標準の約定通知も重複して届きます。

### 通知の種類

| メッセージ | タイミング |
|-----------|-----------|
| `○○ [5] ロング予告（足の確定前）` / `ショート予告（足の確定前）` | 足の途中で条件が揃った最初のティック（未確定） |
| `○○ [5] ロングエントリー（確定）` / `ショートエントリー（確定）` | 足の確定時（例：10:40の足は10:45:00）。次の足の始値で約定 |
| `○○ [5] ロング決済 損益:+0.05` / `ショート決済 損益:…` | 約定した時点（足の途中でも通知） |

### Slackに通知する

TradingViewのWebhookとSlackのIncoming Webhookを使います。

1. Slackで、通知先チャンネルのIncoming Webhook URLを発行する
2. 本ストラテジーの設定で「メッセージをSlack用のJSON形式にする」をオンにする
3. アラートを作成し、トリガーを「alert()関数呼び出しのみ」にする
4. 通知の欄で「Webhook URL」にチェックを入れ、手順1のURLを貼り付ける
5. 作成する（メッセージ欄は触らない）

- Webhookの利用には、TradingViewの有料プラン（Essential以上）と、2要素認証の有効化が必要です
- Slackは `{"text": "..."}` 形式のJSONを受け付けるため、手順2が必要です。オンにすると、アプリ通知やメールにもJSONのまま表示されます
- Incoming Webhook URLは秘密情報です。リポジトリやスクリーンショットに含めないでください

### 注意

- 予告は、足の確定までに条件が消えることがあります。エントリーの判断は確定の通知で行ってください
- 確定ベースのシグナルは、足が終わるまで成立が分かりません。足の名前は開始時刻なので、「10:40」の足の通知は10:45に届きます
- 決済の通知は、TradingView上の想定の約定に基づきます。実際の約定価格・スプレッドとは一致しないため、実運用では証券会社側の逆指値の併用を推奨します

## 表示

- **SMAテーブル**: 最新の足のSMAの価格と向き（上向き・下向き・横ばい）を、白文字でティックごとに更新して表示
- **SMA**: 上向きは水色、下向きはオレンジ
- **背景色**: 売られすぎ状態は薄緑、買われすぎ状態は薄赤
- **ロング条件**: 足の下に緑の三角
- **ショート条件**: 足の上に赤の逆三角
- ストラテジーの約定マーク（矢印と「L」「S」）は、TradingView標準の表示です。数値（例：「-2」）は注文数量で、ドテン時は決済分と新規分を合わせた数量になります

## 検証結果（参考）

USDJPY 5分足、2026-09-28〜2026-11-14（約7週間）。判定本数7、許容本数3、SMA6の初期設定。

| 条件 | 総損益 | PF | 勝率 | 回数 | 最大DD |
|------|-------|----|------|------|-------|
| TP/SLなし・ドテンあり（スリッページ1） | +6.13円 | 2.529 | 65.5% | 58 | 1.42円 |
| TP20/SL10・ドテンなし（スリッページ1） | +1.62円 | 1.193 | 37.6% | 133 | 1.74円 |

パラメーターを動かした場合（TP/SLなし・ドテンあり）:

| 変更内容 | 総損益 | PF | 回数 |
|----------|-------|----|------|
| 判定に必要な本数 6 | +4.85円 | 1.697 | 90 |
| 判定に必要な本数 5 | +1.97円 | 1.186 | 148 |
| 許容本数 1 | +1.68円 | 1.546 | 12 |
| 許容本数 5 | +4.19円 | 1.570 | 86 |
| SMA期間 8 | +7.18円 | 2.975 | 45 |

XAUUSD 5分足（2026-09-21〜2026-11-14）では、TP/SLなしで-563.87ドル（PF 0.514）、TP20ドル/SL10ドル（スリッページ0）で-53.98ドル（PF 0.943）となり、優位性は確認できませんでした。

### 検証の限界

- 期間が約7週間・約60回と短く、別の相場局面での検証が必要です
- ストキャスの期間は動画の元ソースが不明なため、推測した値です
- スリッページはティック数で指定しています。スプレッドの目安は、片道あたり「スプレッド÷2÷最小値幅」です（ドル円0.2銭なら1ティック）
- TP/SLなしは、含み損を抱えたまま保有する時間が長くなるため、大きな負けが出る可能性があります
