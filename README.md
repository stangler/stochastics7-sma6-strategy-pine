# ストキャス7×SMA6 逆張り検証(FX 5分足)

TradingView Pine Script v6 用の逆張りストラテジーです。フィボナッチ数列に基づく7つのストキャスティクス期間と、6本SMAの組み合わせで売買シグナルを生成します。

## 概要

本ストラテジーは、複数のストキャスティクス期間を同時に監視し、一定数以上が買われすぎ/売られすぎゾーンに入った後、SMAの方向性に従って逆張りエントリーを行うシステムです。FXの5分足を想定して設計されていますが、他の時間足や銘柄でもご利用いただけます。

## 特徴

- **マルチ期間ストキャスティクス**: 7つの期間（5, 8, 13, 21, 34, 55, 89）を同時に監視
- **逆張りロジック**: 売られすぎ＋SMA上向きでロング、買われすぎ＋SMA下向きでショート
- **柔軟な判定設定**: 判定に必要なストキャスの本数や、ゾーン到達からの許容本数を調整可能
- **リスク管理**: 利確/損切り（pips指定）、最大保有本数、時間帯フィルターに対応
- **ドテン機能**: 逆シグナル発生時にポジションを反転
- **エッジエントリー制御**: シグナル発生の最初の1本のみエントリーするか、条件継続中は再エントリーするかを選択可能

## インストール

1. TradingViewのチャートを開く
2. パインツリーエディタ（Pine Editor）を開く
3. 本スクリプトのコードをコピー＆ペーストする
4. 「保存」→「チャートに追加」をクリック
5. ストラテジーテストタブでバックテストを実行

## パラメーター設定

### ストキャス期間

| パラメーター | 初期 | 説明 |
|------------|-------|------|
| 短期1 | 5 | ストキャスティクスの期間設定 |
| 短期2 | 8 | 〃 |
| 中期1 | 13 | 〃 |
| 中期2 | 21 | 〃 |
| 中期3 | 34 | 〃 |
| 長期1 | 55 | 〃 |
| 長期2 | 89 | 〃 |

### 判定

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| %K平滑化 | 1 | ストキャスティクスの%K平滑化期間 |
| 買われすぎライン | 80.0 | 買われすぎと判定するレベル |
| 売られすぎライン | 20.0 | 売られすぎと判定するレベル |
| 判定に必要な本数 | 7 | 買われすぎ/売られすぎと判定するために必要なストキャスの本数（1〜7） |
| ゾーン到達からエントリー許容本数 | 3 | 買われすぎ/売られすぎ判定が出てから、この本数以内ならSMAの向きでエントリー。0なら判定が出た足のみ |
| SMA期間 | 6 | エントリー判定に使用するSMAの期間 |

### 売買設定

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| ロング（売られすぎ＋SMA上向き） | true | ロングエントリー有効化 |
| ショート（買われすぎ＋SMA下向き） | true | ショートエントリーを有効化 |
| 逆シグナルでドテン | true | 逆シグナル発生時にポジションを反転 |
| サイン発生の1本目のみエントリー | true | オン：条件が揃った最初の足だけエントリー。オフ：条件が続く間、決済のたびに再エントリー |
| 1pipの価格幅 | 0.0 | 0で自動（最小値幅×10）。XAUUSDで0.1pip扱いにしたい場合などは手動指定 |
| 利確 pips | 0.0 | 0で無効 |
| 損切り pips | 0.0 | 0で無効 |
| 最大保有本数 | 0 | 0で無効。指定本数を超えると時間切れで決済 |

### アラート

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| アラートメッセージを出す | true | アラート作成時の条件で「alert()関数呼び出しのみ」を選ぶだけで、メッセージ入力は不要 |

### 時間帯フィルター

| パラメーター | 初期値 | 説明 |
|------------|-------|------|
| 取引時間帯を限定 | false | 時間帯フィルターの有効/無効 |
| 取引時間帯 | 0800-2400 | 取引可能な時間帯（タイムゾーンに従う） |
| タイムゾーン | Asia/Tokyo | 時間帯の基準タイムゾーン |
| 時間帯の外に出たら決済 | false | 取引時間帯外になったら全ポジションを決済 |

## トレードロジック

### エントリー条件

#### ロングエントリー
1. 指定本数以上のストキャスティクスが売られすぎライン（デフォルト20）以下
2. その状態から`lookback`本数以内
3. SMA（デフォルト6本）が上向き（現在値 > 1本前）
4. `enableLong`がtrue
5. 時間帯フィルターを通過（使用時）

#### ショートエントリー
1. 指定本数以上のストキャスティクスが買われすぎライン（デフォルト80）以上
2. その状態から`lookback`本数以内
3. SMA（デフォルト6本）が下向き（現在値 < 1本前）
4. `enableShort`がtrue
5. 時間帯フィルターを通過（使用時）

### エグジット条件

- **利確**: エントリー価格から指定pipsに到達
- **損切り**: エントリー価格から指定pipsに到達
- **最大保有本数**: 指定本数を超えたら決済
- **時間帯外**: `closeOutside`がtrueの場合、取引時間帯外で全決済
- **ドテン**: `reverseOn`がtrueの場合、逆シグナルで反転

## 表示設定

- **SMA**: SMAが上向きの場合は水色、下向きの場合はオレンジ色で表示
- **背景色**: 売られすぎ状態の場合は薄緑色、買われすぎ状態の場合は薄赤色
- **ロングシグナル**: ロング条件成立時、バーの下に緑の三角マーカー
- **ショートシグナル**: ショート条件成立時、バーの上に赤の三角マーカー
